## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact table cell padding, form field internal gap |
| md | 16px | Default element spacing, sidebar item padding |
| lg | 24px | Section padding within admin pages, card internal padding |
| xl | 32px | Gap between dashboard stat cards, gap between sidebar and content |
| 2xl | 48px | Major section breaks within a page |
| 3xl | 64px | Not used in admin panel — reserved for public hero sections |

Exceptions:
- Touch targets on icon-only action buttons (edit, delete in table rows): minimum 44px hit area via `size-icon` variant (32px visual + 12px padding context)
- Sidebar width: 256px (fixed, does not derive from 8-point scale — matches shadcn sidebar token convention)
- Mobile drawer sidebar: same Sheet component used by public Navbar, full-height, triggered by hamburger button

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter | Table cell content, form field values, audit log entries, description text, stat card labels |
| Label | 14px (text-sm) | 600 (semibold) | 1.4 | Inter | Form field labels, table column headers, sidebar section labels |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Inter | Page titles (e.g., "Itens Banidos", "Servidores"), dialog titles |
| Display | 16px (text-base) | 400 (regular — Press Start 2P renders larger visually) | 1.2 | Press Start 2P | Dashboard section header only ("Dashboard") — one instance per page maximum |

Notes:
- Press Start 2P is reserved for the Dashboard page header to signal entry to the admin hub with brand continuity. All other admin pages use Inter headings at 20px/600 for readability in dense data tables.
- Dashboard stat card numbers: 28px (text-3xl), weight 600 (semibold), Inter — these are the primary data point and must be visually dominant. Size (28px) at weight 600 provides sufficient dominance without requiring a third weight.
- Stat card labels under numbers: 14px (text-sm), weight 400, Inter, color `--color-muted-foreground` — same size as Body role, distinguished by muted color rather than a separate size token.

Source: `src/app/globals.css` (font variables detected) + project design decisions ("colorido vibrante Minecraft/Pokémon")

**Typography scale: 14, 16, 20, 28 (4 sizes). Weights: 400, 600 (2 weights).**

## Interaction Contracts

### CRUD Pattern (all sections)

1. Data table loads as Server Component (no skeleton needed for initial load)
2. "Adicionar" button (top-right of table): opens Dialog with form
3. Row action: DropdownMenu with "Editar" and "Deletar" options
4. Edit: opens same Dialog pre-populated with row data
5. Delete: opens AlertDialog for confirmation before mutation
6. After successful mutation: Dialog/AlertDialog closes + Sonner toast appears
7. After error: Sonner toast with error message, Dialog stays open

### Loading States

- Table rows while Server Action is pending: button shows spinner (Lucide `Loader2` with `animate-spin`), button disabled
- Stat cards on Dashboard: no skeleton — data fetched in Server Component, page waits
- Form submit button: disabled + spinner while action is in-flight

### Skeleton Screens

Not used for this admin panel. All initial data fetches are Server Components — the page renders with data. Skeletons would only be needed if admin sections were converted to client-side SWR/React Query (not planned).

### Pagination

- All CRUD tables: server-side pagination via URL search params (`?page=N`)
- Default page size: 20 rows
- Pagination controls: Previous / Next buttons with current page indicator
- No per-page selector in v1
- Leaderboard admin table: same 20-row pages, filterable by player name + date range via URL params

### Sorting

- Tables are sortable by clicking column headers
- Active sort column shows arrow icon (Lucide `ChevronUp`/`ChevronDown`)
- Sort state via URL search params (`?sort=field&order=asc|desc`)

## States Per Section

### Banned Items Table

| State | Trigger | UI |
|-------|---------|-----|
| Populated | Items exist in DB | Table with rows, actions per row |
| Empty | No items in DB | Empty state: "Nenhum item encontrado" + "Adicionar Item" button |
| Creating | User opens add dialog | Dialog open, form blank, "Criar Item" button |
| Editing | User clicks "Editar" | Dialog open, form pre-populated, "Salvar Alterações" button |
| Deleting | User clicks "Deletar" | AlertDialog confirmation with "Confirmar Exclusão" button |
| Success | Mutation complete | Toast "Item salvo com sucesso." or "Item deletado." |
| Error | Mutation fails | Toast "Erro ao salvar. Tente novamente." |

### Player in Leaderboard Admin

| State | UI indicator |
|-------|-------------|
| Active (not banned) | Normal row, DropdownMenu shows "Banir Jogador" |
| Banned | Row has `opacity-60`, Badge "Banido" (destructive variant), DropdownMenu shows "Reverter Ban" |
