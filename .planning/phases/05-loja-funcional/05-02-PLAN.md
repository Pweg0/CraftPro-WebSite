    - Re-fetch payment from MP API: `new Payment(client).get({ id: paymentId })` — NEVER trust webhook body
    - If `paymentData.status !== 'approved'`, return early
    - Extract `orderId = Number(paymentData.external_reference)`
    - Check idempotency: `db.select().from(orders).where(eq(orders.mpPaymentId, paymentId)).limit(1)` — if exists, return early (D-12)
    - Wrap in `db.transaction()`:
      - Update order: set `mpPaymentId`, `status: 'paid'`, `paidAt: new Date()`
      - Fetch order to get shopItemId and userId
      - Fetch shopItem to get type, rconTemplate, name, duration
      - Fetch user to get minecraftUuid and minecraftName
      - Call `resolveRconCommand(item, user.minecraftName!)`
      - Insert into deliveryQueue: `orderId`, `minecraftUuid: user.minecraftUuid!`, `rconCommand`, `status: 'pending'`

    **2. Create `src/app/api/cron/process-orders/route.ts`:**

    Import: `Rcon` from `rcon-client`, `db` from `@/lib/db`, `deliveryQueue`, `orders` from `@/lib/db/schema`, `eq`, `and`, `isNull`, `lt`, `inArray`, `sql` from `drizzle-orm`.

    Export `const maxDuration = 60` (claim full 60s on Vercel Hobby).

    Export async function `GET(request: Request)`:
    - Check `request.headers.get('Authorization') === 'Bearer ' + process.env.CRON_SECRET` — if not, return `Response('Unauthorized', { status: 401 })`

    **Phase 1 — Mark expired items (D-09: 48h max):**
    - Calculate cutoff: `new Date(Date.now() - 48 * 60 * 60 * 1000)`
    - Update deliveryQueue: set `status: 'failed'` where `status = 'pending'` AND `createdAt < cutoff`
    - Also update corresponding orders: for each expired deliveryQueue item, update `orders.status = 'failed'` where order still isn't already delivered

    **Phase 2 — Lock and fetch pending items (Pitfall 4: prevent concurrent processing):**
    - Select up to 5 from deliveryQueue where `status = 'pending'` AND `lockedAt IS NULL`, ordered by createdAt asc, limit 5
    - If any found, update their `lockedAt = new Date()` using `inArray(deliveryQueue.id, pending.map(p => p.id))`

    **Phase 3 — Process each item:**
    For each pending item:
    - Try: `Rcon.connect({ host: MC_RCON_HOST, port: MC_RCON_PORT (default 25575), password: MC_RCON_PASSWORD, timeout: 5000 })`
    - `await rcon.send(item.rconCommand)`
    - `await rcon.end()`
    - On success: update deliveryQueue `status: 'delivered'`, `deliveredAt: new Date()`, `lockedAt: null`; update orders `status: 'delivered'`, `deliveredAt: new Date()`
    - On catch: update deliveryQueue `retryCount: sql\`retry_count + 1\``, `lastAttemptAt: new Date()`, `lockedAt: null` (unlock for next attempt)
    - Track `delivered` and `failed` counters

    Return `Response.json({ processed: pending.length, delivered, failed })`
