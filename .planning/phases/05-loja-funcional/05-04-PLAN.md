    **Export `getOrders(status?: string, page: number = 1)`:**
    - Check `hasPermission(session, 'pedidos')` — throw if unauthorized
    - Page size: 25 (per UI-SPEC section 6.4)
    - Build query: join orders with shopItems (for item name) and users (for Discord name + Minecraft name)
    - If status provided and not 'all', filter by `orders.status === status`
    - Order by `orders.createdAt desc`
    - Paginate: offset `(page - 1) * 25`, limit 25
    - Also get total count for pagination
    - Return `{ orders: [...], total: number, page: number, pageSize: 25 }`

    Each order in result should include:
    ```typescript
    {
      id: number, status: string, amountCentavos: number, createdAt: Date,
      itemName: string, userName: string | null, minecraftName: string | null
    }
    ```

    **Export `forceRetryDelivery(orderId: number)`:**
    - Check `hasPermission(session, 'pedidos')` — throw if unauthorized
    - Fetch the order — verify status is 'failed'
    - Fetch the corresponding deliveryQueue entry for this orderId
    - If deliveryQueue entry exists:
      - Reset deliveryQueue row: set `status: 'pending'`, `retryCount: 0`, `lockedAt: null`, `lastAttemptAt: null`
      - Reset order: set `status: 'delivering'`
    - If no deliveryQueue entry (edge case): create new entry by rebuilding the RCON command from the order's shopItem + user
    - Log audit: `logAudit(session!, 'FORCE_RETRY_ORDER', String(orderId))` (D-17)
    - `revalidatePath('/admin/pedidos')`
